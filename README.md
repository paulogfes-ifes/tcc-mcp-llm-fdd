# tcc-mcp-llm-fdd
Repositório do Trabalho de Conclusão de Curso em Engenharia de Controle e Automação (IFES).

Este projeto consiste em uma Prova de Conceito (PoC) e em um estudo exploratório sobre a viabilidade de integrar Grandes Modelos de Linguagem (LLMs) em redes de automação industrial. A arquitetura utiliza o Model Context Protocol (MCP) para conectar os modelos a uma malha de controle PID simulada, composta por Node-RED (Planta), OpenPLC (Controle) e Mango OS (Supervisão).

O objetivo principal é isolar a rede de controle e avaliar o desempenho computacional (latência e tokens) de diferentes LLMs na análise descritiva de distúrbios operacionais.
